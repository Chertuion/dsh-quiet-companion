安静陪伴 0.5.1-beta.1

DeepSeek Harness 的 macOS 桌面陪伴插件：沿用默认模型聊天，支持记忆、Agent进度、身边零食与成长，以及可选的画面理解、系统声音转写和语音朗读。

适用：Apple Silicon、macOS14+、Harness0.2.1-rc.5。
安装：插件 → 添加插件 → github:Chertuion/dsh-quiet-companion#v0.5.1-beta.1
旧版0.5.0不含本轮修复。
启用后重新打开 Harness，在“设置 → 安静陪伴”管理。

Q版提供24类动作、192帧关键姿势与网格微动；本机语音可驱动嘴部开合。
新零食出现在角色左右和脚边；右侧成长状态栏默认隐藏，可在成长设置或角色右键菜单显示。
头部、身体衣物和裙摆分开向模型传达触碰语义，每次调用提供实际系统日期、时间与时区。
零食支持窗口未激活时首次点击；无法进食会即时说明原因，仍遵守饱腹、任务、休息和冷却门禁。
观察、画面、系统声音、朗读与鼠标互动默认关闭。无需另填API Key，正常模型调用仍可能产生费用。
选中送给模型的关键帧可能进入Harness本机共享附件缓存；系统音频不保存原始录音。

系统权限应核对独立组件“安静陪伴”。首次授权可能需重启宠物才生效；等待期间可重新检查或取消。
“重新检查系统权限”只读，不采集或自动开启；按需重启后，再明确开启功能。普通设置刷新不再打断同模型确认。
模型兼容单个合法JSON的代码块/说明包装；坏JSON、多个对象或字段不合约仍显示具体错误，不伪造对白。
本轮162项JS/Host SSR、36项权限策略检查及原生协议通过；真实系统授权后的采集和默认模型复测尚待完成。

旧版先停用并卸载，再安装新地址；本插件包外的设置、记忆、等级和库存不会主动清除。
原生组件为本地ad-hoc签名，未做Developer ID公证。
