安静陪伴 · 本机预览版 0.1.0-preview.1

适用环境
Apple Silicon Mac，macOS 14 或更新版本；已安装的 DeepSeek Harness 桌面版 0.2.1-rc.5。

加载
桌面版左侧“插件” → “添加插件”，填入 dsh-quiet-companion-0.1.0-preview.1.tgz 的完整路径。
安装后选择“立即启用”。若应用提示重启，按提示重启桌面版。
不要把 source 目录里的图片或 Swift 源码当作插件安装。

当前实际接通
- 系统桌面置顶透明角色窗口、拖拽与位置记忆、大小和透明度调节。
- 点击摸头、双击聊天、两张表情立绘、简单浮动；右键菜单和菜单栏显示/隐藏。
- 复用 Harness 已配置的模型进行简短文字聊天。
- 在“陪伴设置”选择模型并开启观察后，读取当前应用名称和空闲时长，按节奏请求文字回应。
- 默认暂停观察。暂停/安静期间不分析应用活动；没有配置模型也能拖拽与摸头。

尚未接通
屏幕与视频理解、系统音频、完整动作库、语音、长期记忆、余额与预算功能。
本预览版截图开关禁用，不请求屏幕录制权限，不采集或上传屏幕画面。
它不能根据应用名称判断你看了哪个视频；台词必须以实际可见的元数据为限。

交互
单击角色：本地摸头回应；双击：聊天窗口；右键：设置/暂停/安静30分钟/隐藏/退出。
菜单栏的水滴图标可以找回隐藏的角色。
退出宠物后，可在 Harness 中关闭再启用此插件重新打开。

数据与调用
开启观察后，应用名称、空闲时长和简短上下文会发送给设置里选中的模型服务。
聊天会发送你输入的文字及本次启动期间最近几轮上下文。
仅设置持久化于 DSH_HOME/quiet-companion/settings.json；本版本不保存行为或聊天历史。
自动分析至少间隔45秒，主动发言至少间隔90秒；模型可以选择保持安静。
角色图片与人设仅用于本机预览，不代表任何厂商官方产品。
