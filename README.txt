安静陪伴 0.3.0-beta.1

安装地址：github:Chertuion/dsh-quiet-companion#v0.3.0-beta.1
Harness 桌面版 → 插件 → 添加插件 → 粘贴地址 → 安装并启用。
适用 Apple Silicon Mac、macOS14+、Harness0.2.1-rc.5。

模型跟随 Harness 默认配置，不需要另一套 API Key。
首次使用请在 Harness 设置侧栏打开“安静陪伴”；画面、系统声音、语音均按需开启。
默认模型必须支持图片才能启用画面理解；系统声音识别要求本机离线识别资源和用户授权。
主动发言根据新事件和上下文自适应决定，没有固定轮播的角色台词。

包含画面关键帧、可选本机系统声音转写、真实模型交流、知识图谱与中文检索记忆、真实Agent进度、动态角色动作、系统语音与用量预算。
新增“成长与零食”独立分区：只按启用后的当前Host Agent/子Agent及本插件真实上报用量奖励零食，默认2000 token一份，可设100–100000；不回放历史、不统计其他应用，未知用量不猜测奖励。
库存最多64份具名实体，其余保留储备计数，桌面同时最多显示8份。自动吃之前至少展示4秒；太饱、睡眠、精力低、忙碌或等待确认时暂缓，两次进食至少间隔90秒。
已有模型调用可提出eat/wait意图，最终由本机状态规则执行，不另发模型请求。等级、XP和熟悉阶段不代表角色外观变大。普通互动也可增长XP（5分钟节流、重复递减），不用为成长额外消耗token或付费。
暂停观察与成长开关独立；成长、零食奖励与自动进食可分别关闭。没有死亡、掉级或久别关系惩罚。
选中的画面会经过 Harness 附件服务并可能持久缓存；暂停观察后停止采集和主动感知调用，手动聊天仍按原模型配置计费。
默认模型为 deepseek-account 时可查询现有账户余额；其他服务不伪造余额。

实际部分复用ajuwm/dsh-roleplay-plugin的MIT食品恢复规则、关系分级与重复互动递减，完整许可和固定提交已保留；未接入其完整预设/角色卡/日记/纪念日/多角色/小游戏。Open-LLM-VTuber仍仅为调研，Live2D、麦克风连续对话与用户语音打断尚未接入；未安装额外XP库。

细节、数据目录、操作方法、验证边界和开源来源请阅读 README.md 及 THIRD_PARTY_NOTICES.md。
