安静陪伴 0.5.1-beta.2

DeepSeek Harness 的 macOS 桌面陪伴插件：沿用默认模型聊天，支持记忆、Agent进度、身边零食与成长，以及可选的画面理解、系统声音转写和语音朗读。

适用：Apple Silicon、macOS14+、Harness0.2.1-rc.5。
安装：插件 → 添加插件 → github:Chertuion/dsh-quiet-companion#v0.5.1-beta.2
GitHub源码下载停滞时，可使用同版Release的.tgz安装包，无需解压。
启用后重新打开 Harness，在“设置 → 安静陪伴”管理。

Q版提供24类动作、192帧关键姿势与网格微动；本机语音可驱动嘴部开合。
新零食出现在角色左右和脚边；右侧成长状态栏默认隐藏，可在成长设置或角色右键菜单显示。
头部、身体衣物和裙摆分开向模型传达触碰语义，每次调用提供实际系统日期、时间与时区。
零食支持窗口未激活时首次点击；无法进食会即时说明原因，仍遵守饱腹、任务、休息和冷却门禁。
观察、画面、系统声音、朗读与鼠标互动默认关闭。无需另填API Key，正常模型调用仍可能产生费用。
选中送给模型的关键帧可能进入Harness本机共享附件缓存；系统音频不保存原始录音。

系统权限应核对独立组件“安静陪伴”。首次授权可能需重启宠物才生效；等待期间可重新检查或取消。
“重新检查系统权限”只读，不采集或自动开启；按需重启后，再明确开启功能。普通设置刷新不再打断同模型确认。
模型兼容单个合法JSON的代码块/说明包装；坏JSON、多个对象或字段不合约仍显示具体错误，不伪造对白。
beta2新增头部、衣物、裙摆及“递给她：食品名”的无障碍Press入口，复用实际互动/递食处理；不授予鼠标控制权限，隐藏或不可用时不能触发。
beta1已通过165项JS/Host SSR、41项权限策略检查和build8完整协议，并从公开Release同hash包完成实际Desktop安装复核。
beta1真实重启后屏幕权限已就绪、画面开关开启不循环（观察保持关闭）；默认Flash中文时间问答及原生菜单递食一份、+20XP/进食动画已验证。
beta1系统声音曾开启未崩溃，屏幕/Speech授权就绪；观察关闭，转写质量未测。真实帧到模型链路可达，受控窗口未采中，不能写受控OCR准确性通过。
beta2通过169项Node.js24＋实际Host React测试（0失败/0跳过）；build9完整LS协议、41项权限/32项AX对象/15项音频状态纯检查通过，修复暂停观察时旧音频提示残留。
短回应与聊天分别使用2048/4096生成上限，更低服务端配置优先；保留Harness默认模型和推理强度，达到上限中文提示且不自动重试。
真实AX操作、零食本体直接点击、全部OS能力、模型格式失败根因和beta2实际Desktop安装尚未据此确认。
